## Raw Concept

K67 — **personal OS** pattern: single Claude Code workspace spanning life-ops, trading, content creation. CCC documents as **anti-pattern for Cemini prod** (keep financial stack narrow) and **template for laptop CCC** sessions only.

## Narrative

### Scope creep risks [TENTATIVE]

- One workspace → unbounded MCP/tools → permission sprawl.
- Trading journal + content + infra in one context window → conflated decisions.
- Harder Phase-0 auditing when "everything" shares hooks/skills.

### Cemini discipline

| Surface | Scope |
|---------|--------|
| **CeminiSuite prod** | Markets, signals, governed briefs — not general life-ops |
| **CCC wiki** | Harness, agents, MCP, patterns |
| **OSINT wiki** | Research corpus |
| **Personal laptop** | Optional personal-OS experiment in **separate** project folder |

### Verdict

**REFERENCE (CCC template only)** — open separate Cursor/Claude roots per `CLAUDE.md` Related Wikis table; do not merge prod and personal OS.
