## Raw Concept

What architectural changes does the web need when agents — not humans — are primary content consumers?

## Narrative

**Agent-first internet** [TENTATIVE — vision paper, 2606.19116]: ten design principles across access, economics, and content — must be redesigned **together** (principle 10).

### Ten principles (abbreviated)

1. Presumption of agent access (default allow for anonymous-human-open resources)
2. Behavioral contract over identity mandate (intent declaration, not mandatory ID)
3. Rate limiting as universal access control
4. Economic equivalence to represented human (agent-as-human-proxy)
5. Token as unit of value exchange (replaces pageview/impression)
6. Publisher economic sovereignty (machine-readable terms)
7. Provenance as first-class property
8. Human supervision declared (tier model, not assumed)
9. Dual-layer coexistence (HTML + ATML from same source)
10. Simultaneous three-layer redesign

### ATML + epistemic recursion

| Threat | Response |
|--------|----------|
| HTML token overhead (~67.6% layout noise cited) | ATML semantic delivery; `Accept: application/atml+xml` negotiation |
| AI-on-AI content loops | Supervision tiers + cryptographic provenance chain |

**Near-term deployables:** `Agent-Identity` / `Agent-Intent` headers, `agents.txt`, extended `llms.txt`.
