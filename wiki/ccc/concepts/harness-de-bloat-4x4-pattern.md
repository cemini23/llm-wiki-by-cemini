## Raw Concept

K73 simplification argument: most teams overfit with large skill/agent catalogs. Start with a small, explicit core (4 skills / 4 agents), then add only when measurable gaps appear.

## Narrative

| Dimension | De-bloat baseline |
|-----------|-------------------|
| Skills | 4 core skills, no duplicate purpose |
| Agents | 4 role-specialized agents max |
| Additions | Require benchmarked need + rollback plan |

This is a **complexity-control pattern**, not a hard law.
