## Steal / policy bullets (write these, cited)

**K300:** six-agent pipeline; Skeptic falsifies but never repairs; closed-loop repair then **re-admit** before acceptance. OOD — one source stub.

**K301:** Prompt → Context → Harness → Loop Engineering is insufficient for heterogeneous multi-agent work; **Graph Engineering** = explicit evolving graphs of tasks/agents/state (**System Intelligence**). Policy vocabulary only; no awesome-list clone.

**K302:** Authorization at admission is not authorization-to-effect. Revalidate exact approved request + provider state at commit; retain one reservation while outcome is ambiguous; at most one successor after certified no-effect + delivery fence. 13 live mutations / 210 Stripe trials / 44 compromise attacks (paper). Pairs K239 execution fidelity + K285 Mandato.

**K303:** ChatGPT trusted more than Google for health answers (N=21); text vs speech vs embodied UI changes trust (N=20). OOD — stub + K247 pointer.

**K304:** Plain false assertions at **1.2%** of corpus drop LongMemEval **0.850 → 0.300**. Four-stage write-time content screening (0.832 recall on indirect injection) refused **0/360** poisons — content screening cannot see payload-free lies. Additive provenance ranking has **no usable weight** (shipped weight p=0.80 vs none; high weight excludes untrusted evidence categorically). Prefer **bounded occupancy** of untrusted memories, not an additive score. Require **external grounding** for write-path truth. No poison PoCs in wiki.

**K305:** MCP as RL env interface; env-orchestration (isolate/recycle per trajectory) + rollout-orchestration (overlap tool stalls). Trainer **wont_wire**. Clone REFERENCE only.

**K306:** MCP-grounded RCA (K8s/Prometheus/Loki/NATS) named correct root cause in **10/10** faults, MCP success **0.91**; engineers trusted diagnosis but **not** the recommended fixes (**diagnostic/prescriptive asymmetry**). Do not auto-apply agent remediations. Dual-ID vs K253.

**K307:** Four typed banks (skills / process rules / schemas / measurement) with provenance, support, replay, controller safety; publish into a **frozen test-time snapshot**. Process-Constrained Preference Harness rejects controller-invalid candidates. Clinical OOD — pattern only; no unattended skill evolve.

**K308:** Agents are **intermediary engineers** that train lightweight forecasters from few examples + text; not LLM-as-forecaster. Meta-harness loop (pairs K281) with **external** eval — do not rewrite pass criteria. Clone REFERENCE; no TSF runtime on CCC.

**K309:** Persistent IPython REPL (RLM) + Continual Harness (histories/memories/skills/prompts/subagents across trajectories) + recursive subagents + Agents View. ARC-AGI-3 RHAE Best@1 **30% → 95.5%** (paper). Standardized execution/recovery/verification so harness failures ≠ model failures. Clone REFERENCE; **HITL before any skill/prompt self-write** (K162 / misevolution). Do not swap `/route` or Cursor for Prime Agent.
