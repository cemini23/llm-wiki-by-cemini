## Steal bullets

**K333:** Treat the model as **untrusted**; never gate authority inside model reasoning. Bearer credentials + model-gated actions fail all four delegation threats. External authorization broker with scoped delegation closes the gap at ~2.6µs/decision.

**K334:** Evaluate **harness infrastructure**, not only answers. Creation vs Evolution are distinct skills. Visible feedback ≠ held-out transfer; executor swap can negate gains. State defined in code often **never triggers** — integration verify required.

**K335:** Wrap existing harnesses; do not rebuild from scratch. Balance repair with capability growth; scope increments; independent eval gate; versioned history. Multi-day trajectories need meta-loop discipline.

**K336:** Teardown **order** changes final state. LLM lifecycle reasoning does not scale; when dependencies are formal, **compute or execute-verify** instead of trusting model anticipation.
