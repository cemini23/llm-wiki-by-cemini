## Narrative

Latent Space published this AINews issue for 10/27/2026–10/28/2026. The issue says the team checked 12 subreddits and 544 Twitters and checked no further Discords. The lead item is Google DeepMind's Gemini 4 Carbon. The issue says DeepMind announced Carbon two weeks after Argon and positions Carbon as state of the art on cybersecurity and long-horizon tasks.

The issue quotes these cyber scores from one X account. Carbon scores 88.2% on SEC-bench Pro for vulnerability finding, 54.8% on ExploitGym for exploitation, and 71.0% on CWE-bench for patching. These figures are single-source claims in this issue. Carbon first goes to trusted cyber defenders through the Fairwind Program. Wider developer access is promised "as soon as possible." The issue reports two prices. Phil Schmid quotes $2/$10 per million input/output tokens. Artificial Analysis lists $4/$20 standard pricing with a 50% launch discount that has no end date, and cached input at $0.20 per million tokens. The issue says the model has a 1M-token context window and 1M max output.

Artificial Analysis ranks Carbon #1 on Intelligence Index v5 with a score of 59. That score is a single-source claim in this issue. Carbon leads 4 of the 9 index evals: HLE-Diamond, TB-Science, AA-Omniscience, and AutomationBench. On the Coding Agent Index, Carbon scores 59 using Antigravity CLI, against 62 for Claude Code with Opus 5.5 [max]. Carbon scores 51% on FrontierCode v1.1, against 56% for Opus. The issue says Carbon costs $7.76 per index task, against $10.04 for Opus 5.5 and $6.25 for GPT-6 Astra. Carbon uses 123k output tokens per task, 29% fewer than Opus. The issue says Carbon's hallucination rate rose from Argon's 4% to 11%.

The harness limit matters for a coding-harness reader. The issue says these coding-agent results were measured in Antigravity CLI, so results in other harnesses are untested. The issue also says the default system prompts of 30 open coding harnesses range from 235 tokens in goose to 11,974 tokens in Gemini CLI, before any tool definitions. GitHub Copilot Fusion orchestrates Anthropic and OpenAI models at runtime. The issue says Fusion scores 2 points below Opus 5.5 in Claude Code on the AA Coding Agent Index, costs $5.59 per task against $11.42 for that setup, and uses 7.2M tokens per task. The issue says Fusion leads Terminal-Bench 4.0 with a score of 71. T3 Code lets one thread drive multiple models, harnesses, and machines through one MCP server.

The same issue reports a leaderboard reset. The rebuilt AA Intelligence Index v5 runs 60% on private tests. Before Carbon, the issue lists Opus 5.5 at 58, GPT-6 Astra at 57, GPT-6.1 Sol at 55, Sonnet 5.5 at 54, and GPT-6.1 Terra at 51. A cited comment calls list-price cost comparisons fragile. A Reddit recap in the issue reports a Claude Code user whose output per 1% of weekly quota fell from 119K tokens to 31K tokens, and the post attributes that change to possible harness behavior. Every number in this page is a claim from this one newsletter.
