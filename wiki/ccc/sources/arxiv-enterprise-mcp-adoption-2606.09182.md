## Narrative

First **empirical enterprise adoption** study for MCP in LLM-driven software engineering (vs benchmark/security-only prior work).

**Value cited:** cross-system collaboration, task decoupling, knowledge reuse.

**Adoption constraints:** ecosystem fragmentation, cross-component coordination, distributed state management, fault diagnosis gaps.

**Practitioner demands:** better standardization, low-code/plugin adoption paths, systematic operational support.

**CCC relevance:** validates lazy-tool + catalog curation + fault taxonomy + SeClaw eval stack as responses to named enterprise bottlenecks.
