## Narrative

Conceptual framework for training **agentic engineers** (not prompt engineers). **ACCEL** five pillars: (1) intent specification / problem framing, (2) orchestration / delegation, (3) verification / validation / critical evaluation, (4) ethical governance / accountability, (5) adaptive self-directed learning. Delivery via curricula, collaboration, continuous learning.

**Risks:** automation bias, deskilling, superficial engagement, diffuse accountability. Evidence cited: AI tooling sometimes slows work while users *feel* faster (misperception). Shift instruction from artifact production → judgment over autonomous systems.

| Verdict | **ADOPT** ACCEL pillars as operator-education / skill rubric framing. **NO-GO** install (paper only). Strong David/TipDrop brief |
