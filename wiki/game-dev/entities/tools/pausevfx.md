### The offer

A natural-language video editor (Pause 1.0 Flash). One prompt cuts footage, adds zooms, places SFX, and generates captions. A 28-second demo skill exists for Claude and Cursor (`opus-pause-one-prompt` on LaunchFable).

### Why it is Watch and not Extract

Three unknowns, all behind a sign-in wall:

- No published pricing tiers
- No watermark policy
- No maximum resolution or duration
- No API

A 28-second skill demo is a handoff sample, not a programmatic surface. Nothing can be wired against it today.

### If it opens up

The play is a clip pipeline for Basgiath: VoiceStudio produces local voice and dubbing, Pause cuts and captions. That is a real time saving on short-form output — but only if an export path exists.

### Constraint that survives any adoption

Basgiath clips must carry zero official book text, zero official artwork, and no protected series names in titles, and must be labelled fan-made.
