## Narrative

The paper treats e-commerce query understanding as one sequence-to-structure generation task, replacing a pipeline of separate taggers. It targets multilingual shopping queries at Alibaba scale.

**Relevance to this wiki: poor.** This is marketplace search infrastructure, not web search and not generative-engine citation. Nothing here changes how a site earns a citation in an AI answer or ranks in a local pack. The only thread is that both concern how a machine reads a query — that is a shared subject, not a shared method, and it is not worth building on.

`[TENTATIVE]` — assessed from the abstract and introduction only. The method and numbers were not verified.
