## Narrative

`markdown-preview-pluk` (pluk-inc/markdown-preview) is a native macOS markdown previewer with live LaTeX + Mermaid diagram rendering. Tangentially relevant to the 3D-printing wiki because the wiki itself is markdown-based — any author reviewing or editing 3D-printing pages on macOS can use it as a faster preview path than browser-rendered markdown.

This is a **workflow tip for the wiki author**, not a 3D-printing stack component. The tool is tracked canonically in `@osint-wiki/entities/tools/markdown-preview-pluk.md`; this stub exists only to prevent redundant rediscovery if a future ingest into 3D-printing-wiki picks up the same URL.
