## Raw Concept

Image-gen K293, 2026-10-20. One visual tool-use paper, routed from the osint inbox. No install. No weights.

## Narrative

OpenVLHarness is a multimodal tool harness with a capability layer and a persistent memory of images, tables, and web references. On 22 benchmarks and eight backbones it gains **9.7–12.6** points over a matched no-tool baseline. Spending more inference on the base model, with no tools, yields only modest gains. The code is at `github.com/uclanlp/OpenVLHarness`. **REFERENCE only. No clone in this pass.**
