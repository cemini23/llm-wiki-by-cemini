## Narrative

Repeatable **multi-agent research pipeline** beats single-chat "play five personas in one prompt" when five structural gates are explicit:

| Gate | Role | Failure mode if missing |
|------|------|-------------------------|
| **Intake** | Lead reframes vague asks (horizon, risk, universe, goal, constraints) | Team answers wrong question |
| **Specialist** | One judgment angle per agent (filters, not cosplay) | Mushy blended opinions |
| **Adversary** | Bull/bear (or Buffett/Graham) forced disagreement | Echo chamber |
| **Lead** | Assigns work, synthesizes, no hot takes | Fragment pile |
| **Memo** | Decision record with invalidation + next research steps | No learning loop |

**Cemini mapping:** Conductor already routes wiki/kb specialists; Devil's Advocate / brief-audit layers cover Adversary + Memo. Gap: formal **Intake gate** on user queries (horizon/risk/universe) before expensive prod-touching briefs [TENTATIVE].

Buffett/Graham example: translate "legend personas" into **executable filters** (moat vs margin-of-safety), not voice imitation — aligns with TradingAgents structured communication [CONFIRMED] via @sources/tradingagents.md + K98 post.
