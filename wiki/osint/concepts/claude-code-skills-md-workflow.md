## Narrative

### Skills.md vs stateless prompting

- **Problem:** AI coding assistants forget team conventions every session.
- **Skills.md:** reusable markdown "skills" (standards, deploy flows, test gates, security rules) loaded persistently in Claude Code.
- **Shift:** from "ask AI questions" to "build reusable intelligence layers."

### CLAUDE.md five-section template

1. **Role** — specific operator persona, not generic assistant.
2. **Style** — concise, bullets, numbers over vagueness.
3. **Constraints** — never invent data; never commit without tests.
4. **Workflow** — step pipeline (e.g. ingest: read → summarize → file → index).
5. **Quality** — pre-delivery checklist.

Hierarchy: **system setup (CLAUDE.md / Skills.md) → prompts → output**. Matches Cemini OSINT `CLAUDE.md` schema and prod subsystem CLAUDE.md recommendation (@concepts/cemini-repository-topology.md).

### vs Hermes

Hermes = runtime agent memory product. Skills.md = **version-controlled repo artifacts**. Cemini uses both patterns in different layers (wiki schema + stash episodic memory on librarian).
