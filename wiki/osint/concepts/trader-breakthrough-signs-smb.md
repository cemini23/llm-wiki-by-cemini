## Narrative

### Learning curve phases (SMB) [TENTATIVE]

| Phase | Months | Character |
|-------|--------|-----------|
| Chaos | 1–6 | Steep learning; P&amp;L secondary to process |
| Grind | 7–12 | Rule-following improves; many still break-even |
| Valley | 13–18 | Progress invisible in P&amp;L; most quit here |

### Five pre-breakthrough signs

| # | Sign | Interpretation |
|---|------|----------------|
| 1 | **Bored the right way** | Setups feel mechanical; less excitement = more process consistency |
| 2 | **Fewer trades, more money** | Selectivity ↑; per-trade P&amp;L skew improves |
| 3 | **One-sentence edge** | Can articulate situation → expected participant behavior → what happens next (not "I trade momentum") |
| 4 | **Losses don't wreck the day** | Losses = information; can name next 3 opportunities from failed trade context |
| 5 | **Tracking execution metrics** | Input metrics (rule follow, entry quality, % of available profit captured) over P&amp;L obsession |

### Execution metric game (sign 5 detail)

Compare actual exit vs **ideal system exit** on same size → measure % of available move captured; track weekly [TENTATIVE].

### Cemini relevance

Desk-development framework — useful for paper-trading graduation gates and analyst self-assessment rubrics; not deployable as automated signal.
