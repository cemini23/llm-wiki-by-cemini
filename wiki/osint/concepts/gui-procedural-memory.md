## Raw Concept

What this page answers: how computer-using agents can remember *procedures visually* — not just recognize controls — so they know which workflow is active and which control matters next.

## Narrative

Visual Skill Cards bind reusable GUI procedures with applicability cues, visual evidence, and verification signals; a distilled student (CardDistill) acts without runtime retrieval. Visual sibling of the text agent-skill family (SKILLER/K233). Potential Atto relevance for Antenati/portal cassette automation; no public artifact at Phase-0 check.
