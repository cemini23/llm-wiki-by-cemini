## Raw Concept

K266 cluster hub. Dual-ID **OSINT K266**. SEO-side material only — no Jev product content, no Atto product content. Sibling wiki `@seo-wiki` owns the method.

## Narrative

Two X items with SEO relevance. One is a genuine internal-linking playbook; the other is a generic harness tutorial that is useful as a structural voice model.

**@borjafat — 8 internal linking hacks.** 200 likes / 876 bookmarks / **400,800 impressions**. Method: Search Console export → topic groups → pillar per topic → money pages per group → support posts → articles stuck at **positions 11–20** → footer links → varied link text written for the sentence it sits in. The agent output that matters is a **specific source sentence plus a specific destination**. Working list schema: source page, destination page, link text, containing sentence. Sample limit is stated by the author: **11 Mailchimp articles, no ranking test.** The **Distribb** CTA is advertorial — avoid. **SEO wiki owns this method; not Jev, not Atto product.**

**@shreyanshpatni_ — Custom Agent Harness.** 52 likes / **5,665 impressions** — weakest of the wave. Value is structural: `Agent = Model + Harness`, three core modules, one-middleware-one-concern, deterministic behaviour in code not prompts, observability from day one, small evaluation set, five-stage growth path. Steal **structure only**; the metrics do not justify promoting it as a model.

**Cemini23 voice notes.** Combined with the three Jev items this becomes a five-long-form style pass. Full rows, snippets, and steal/avoid flags live in `@briefs/2026-09-19_k266-seo-voice.md`. Headline steals: open on the loop cost then one table of question types (@sydneyrunkle); the "if it creates text, LLM; if it picks or scores, Jev" decision rule (@0xMovez); the one-tip `TIP 00N` format (@parcadei); pain opener plus eight-step playbook plus GSC artifact (@borjafat); framework-counts structure (@shreyanshpatni_). Avoid: "game-changer", the 200x/400x numbers as bare fact, Distribb-style CTAs, and the Public API advertorial framing.

**Routing.** Topic routing stays in OSINT; operator voice and the Article queue stay in SEO. Ingest stays in the OSINT repo.
