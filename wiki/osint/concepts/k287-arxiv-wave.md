## Raw Concept

K287 arXiv hub. Eight papers. Dual-ID OSINT K287. No training wire. No rule change, so no agent-wiki brief.

## Narrative

### What the eight papers say

- **2610.11542 Constitutional gating.** A constitution plus a hard gate does not make unlocks reliable. Atomic purge plus a canonical recovery message escapes a compliance deadlock 5 of 5 times. LLM-only steering escapes 0 of 5. This confirms the existing deterministic-recovery rule. It does not change the rule.
- **2610.11766 Intent recovery.** The same non-harmful outcome can mean a refusal, a missed task, or a different task. Report operative understanding rate next to attack success rate. CC BY 4.0. No install of the IRIS repo.
- **2610.12274 HarnessSQL.** Train the SQL agent inside the harness, not on static queries. Qwen3-8B execution accuracy moves from 15.5 percent to 45.2 percent on Spider 2.0-SQLite. CC BY 4.0. The desk rule stays FILE. No training wire. No brief, because the rule does not change.
- **2610.12289 TestPrism.** A single reference solution overstates test quality. Joint Success Function is 28.00 percent where single-reference success is 59.67 percent. CC BY 4.0. Measurement note only.
- **2610.12341 AAArena.** Agents revise game code while model weights stay fixed. Opus 5.5 with Claude Code takes 6 gold medals of 12 games. CC BY 4.0. No weight-training wire.
- **2610.12360 Epistemic humility.** Higher task accuracy does not mean the agent states its uncertainty. Conflicts show up early and drop later. CC BY 4.0.
- **2610.12363 HANS.** Handwritten answer sheets with formula, text, and strike-through noise. The PDF licence is the arXiv non-exclusive distribution licence. The dataset is not public yet. That licence does not allow a genealogy-kit brief.
- **2610.12369 Embodied Turing Machines.** Code-only policy, no model in the control loop. The figure shows 70.24 percent success on RoboDojo. **No training wire.**

### Boundary
