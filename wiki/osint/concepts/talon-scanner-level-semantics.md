## Raw Concept

Question this page answers: when a scanner prints a level list, which numbers are entries, which are targets, and which are boundaries?

From one Glitch SPX / Talon weekly (2026-11-15) that defines its own terms.

## Narrative

Five level types, each with a different meaning.

OTE (best entry) is a quoted pullback reference. When it sits above spot in a bullish setup, the report calls it a reclaim reference instead — price must get there first.

Execution reference is the current snapshot zone. It is not an executable price now.

Hold / retest reference is a level to study for acceptance, not a signal to chase the first break.

Structural invalidation is the boundary past which the setup needs reassessment. It does not imply an order or a guaranteed fill at that price.

GEX and VEX are separate dealer-exposure structures: near-term gamma targets and a broader vanna ladder. They are not one sequential path, so a nearer GEX level can sit below a farther VEX level without contradiction.

Three rules that prevent self-deception. An expired anchor is dead and must be refreshed; a live-dated level elsewhere in the same map does not revive it. A farther target never extends a structure whose boundary broke. A sector list where the ETF and its constituents disagree is not a sector call.

The scanner's own pulse counts are classifications, not probabilities. A 95.5% bullish mix is a description of the scan, not a forecast.

[TENTATIVE] One publisher's convention. Other scanners may define these terms differently.
