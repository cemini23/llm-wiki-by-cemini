## Narrative

TDHook is an open-source PyTorch interpretability library built on top of `tensordict`, designed to handle composed/heterogeneous models (multi-input/multi-output networks, multi-modal pipelines, deep RL actor-critic systems) that the standard interpretability toolkits (`captum`, `nnsight`, `pyvene`, `transformer_lens`, `zennit`) do not natively support. It unifies three method classes — attribution, latent manipulation, and weights-based analysis — behind a single get-set intervention API and a hooking mechanism applicable to any `torch.nn.Module`.

The author's core claim is that existing frameworks force users to duck-tape disparate methods together for modern pipelines (concept relevance propagation, attribution patching, DRL agent diagnosis). TDHook provides >25 ready-to-use methods, claims ~50% less disk usage than `transformer_lens`, and reports a ~2x speedup over `captum` on integrated gradients for multi-target pipelines on both CPU and GPU.

Relevant to Cemini because the RL/MARL stack uses composed actor-critic networks where post-hoc attribution (Captum-style) has been a workstream — if TDHook's `tensordict` alignment with TorchRL holds up, it may be the more ergonomic choice for interpretability passes on the 5-agent MAPPO ensemble. Honest limit: this is a framework paper with benchmarks against peer libraries; no novel interpretability method is introduced. Adoption value hinges on whether TorchRL's tensordict workflow survives in production.

## Key findings

- TDHook ships 25+ methods, 95% test coverage; comparative table positions it as the only library supporting all four of {any-torch, tensordict, get-set API, composable} (p.4).
- Claimed benchmarks: ~2x speedup vs `captum` on integrated gradients for multi-target pipelines; ~half the disk footprint of `transformer_lens`.
- Three use cases demonstrated: CV (multi-modal composed), NLP (Transformer interventions), DRL (composed policy networks).
- Finance explicitly cited as a target domain (Zhou et al., 2025 reference).
- Framework paper, not a methodological contribution — no new attribution algorithm introduced.
