## Narrative

This paper tackles uncontrolled memory growth in long-horizon conversational agents. Persistent memory supports coherence and temporal reasoning, but unbounded accumulation drives up retrieval noise, latency, false-memory propagation, and computational cost. Cited benchmarks frame the problem: LOCOMO/LOCCO show performance decay from 0.455 to 0.05 across temporal stages, and MultiWOZ 2.4 reports 78.2% accuracy with a 6.8% false-memory rate under persistent retention. Existing approaches (hierarchical memory, context compression, write-time filtering, decay simulations) each address only part of the problem and never jointly measure performance, memory size, and efficiency.

The contribution is an **adaptive budgeted forgetting framework**. Each memory unit receives an importance score I(mᵢ,t) = α·R(mᵢ,t) + β·F(mᵢ) + γ·S(mᵢ,qₜ), combining temporal recency R, usage frequency F, and semantic alignment S with the active query. Recency uses exponential decay R(mᵢ,t) = exp(−λ(t−tᵢ)) for smooth attenuation rather than binary eviction. Under a fixed budget B, retention is cast as a constrained maximization — select the memory subset M′⊆Mₜ with |M′|≤B that maximizes cumulative relevance. A global objective L_total = L_task + η·(|Mₜ|/B) penalizes excess memory usage while preserving task accuracy.

Evaluation is largely comparative/literature-grounded across LOCOMO, LOCCO, and MultiWOZ. The framework reports long-horizon F1 above the 0.583 strongest-baseline level (full-dynamic reaching >0.643), reduced false-memory rate, and stable performance under bounded memory growth — gains achieved without increasing context usage. The key claim: structured, relevance-guided forgetting under a budget preserves reasoning consistency while preventing unbounded growth, whereas isolated mechanisms (filtering alone, compression alone) are insufficient.
