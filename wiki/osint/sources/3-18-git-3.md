## Narrative

Infrastructure gap-analysis for Cemini, covering: (a) **TimescaleDB chunking** — finer-grained recommendations than the `3_19 TimescaleDB` doc, addressing chunk sizing for specific data types; (b) **OpenCLI / CDP** — evaluation of OpenCLI and Chrome DevTools Protocol for browser automation and debugging; (c) **Kavach EDR** — endpoint detection and response tool noted for securing the Hetzner VPS; (d) **chartdb** — database schema visualization tool; (e) **skilgen** — skill generation tool for the agent layer.

Standard Cemini architect's-memo format: each item has fit judgment, license notes, integration-effort estimate, and strategic value. Kavach EDR and chartdb are concrete adopt-now items; OpenCLI/CDP and skilgen are evaluate-further. TimescaleDB chunking recommendations are extensions of existing Cemini posture.

Useful gap-analysis with specific tools named. Not research. Companion to the other 3/18 audit (`3-18-git-research`) — this one focuses on infrastructure while `3-18-git-research` focuses on agent state/quality.
