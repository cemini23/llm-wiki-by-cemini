## Narrative

A podcast from OpenAI DevDay 2026. Two speakers.

Ari Weinstein, the Computer Use lead, argues that computer-use agents improved sharply and now often beat an average human on a task, and can self-debug. He describes the Agents API carrying Computer Use, a product called Dots where each persistent agent gets a cloud Linux computer, and "app shots" that pair a screenshot with accessibility and DOM metadata.

Nikunj Handa, the API product lead, covers async tool calling, mid-turn steering, WebSockets, an ultrafast inference path, caching, and a new Decisions API. The Decisions API is described as a fast parallel wrapper for classification, not a new model.

Figures quoted: GPT-6.1 Sol at about a fifth of Astra's cost, a 7-times computer-use speed improvement, an 80% Luna price cut, a 12-hour cache guarantee in preview, and a 1M-token context.

This is a tooling headline. Several claims are the vendor's own framing, not independent measurements. It does not change `/route`. Do not swap `/route`. No level to arm. FILE only.
