## Narrative

A programming-languages paper (arXiv 2604.11767, Apr 2026) arguing that LLM agent frameworks lack formal semantics — there is no principled way to decide whether an agent configuration is well-formed or will terminate. The contribution is **λA**, a typed lambda calculus for agent composition: it extends the simply-typed lambda calculus with four agent-specific constructs — oracle calls (LLM invocations), bounded fixpoints (the ReAct loop, written fix_n), probabilistic choice, and mutable environments (persistent memory). It has 11 term formers, a type system, and both small-step and big-step operational semantics. The author proves type safety, termination of bounded fixpoints, and soundness of derived lint rules, with a partial Coq mechanization (1,567 lines, 43 completed proofs).

Practically, λA's operational semantics yield a lint tool — `lambdagent` lint, a Python DSL with a `from_config` compiler — that detects structural configuration errors directly from the semantics: a missing terminate tool means the case expression has no base case, so fix_n exhausts all steps (forced truncation rather than clean termination, rule L004); maxSteps=0 reduces to a stuck term (L003); a router with no default branch is a non-exhaustive case (L013). Evaluated on 835 real-world GitHub agent configurations from 17 repositories and 6 frameworks: **94.1% (786/835) are structurally incomplete** under λA — the YAML alone is not a well-formed lambda term. Stratification matters: much of this is CrewAI declaring tools in Python rather than YAML, so a framework-aware lint v3 splits findings into genuine ERRORs vs framework-handled INFO, dropping L004's effective false-positive rate from ~82% to <5%. Fault injection achieved 100% precision/recall on 42 known faults; manual sampling estimated YAML-only precision at 54% (comparable to FindBugs/Pylint), rising to 96–100% under joint YAML+Python AST analysis. A key empirical finding: ~46% of production configs split their semantics across YAML and Python code ("semantic entanglement"). Finally, five mainstream paradigms — LangGraph, CrewAI, AutoGen, OpenAI/Claude SDK, Dify — are shown to embed as typed λA fragments, positioning λA as a unifying calculus for agent composition.

**Cemini relevance**: Directly relevant to the conductor — λA gives formal semantics for agent composition (well-formedness, termination guarantees, semantics-preserving refactoring) plus a lint approach that could statically catch mis-configured routing or non-terminating loops in Cemini's multi-agent orchestration.
