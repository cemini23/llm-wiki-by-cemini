## Narrative

This is the fourth multi-wiki tool evaluation document (v4), rigorously evaluating 40 distinct repositories, platforms, and infrastructural components against a strict anti-hallucination protocol for Cemini ecosystem integration. The evaluation enforces two gates: (1) **license safety** — copyleft contagion (AGPL-3.0, SSPL-1.0, EUPL-1.2, PolyForm-Noncommercial, CC-BY-SA-4.0) is an automatic rejection for any IP-sale-bearing surface; (2) **architectural fit** — tools must demonstrate verifiable compatibility with existing topologies (PostgreSQL/Redis Streams, ComfyUI, SKILL.md).

### Key findings

1. **AGPL-3.0 remains the primary poison pill** — VERT (14.8k stars) and Repowise (1.6k stars) were rejected on license alone despite excellent technical fit. The paradigm-vs-license inverse correlation continues to hold.

2. **NO LICENSE FOUND = automatic rejection** — Nuclei Templates Collection and Nowledge Mem both rejected despite technical merit. Default copyright law prohibits all reproduction without explicit license.

3. **MCP standardization is accelerating** — Octocode MCP, Beever Atlas, and Nowledge Mem all implement MCP servers, confirming the protocol as the emerging standard for LLM-tool integration.

4. **Hardware-level optimization trend** — Turbovec's SIMD NEON kernels and image-blaster's WebAssembly compute signal a shift toward aggressive hardware-specific inference on local M-series silicon.

5. **10 UNAVAILABLE domains** — underscores that external tooling is inherently fragile; Cemini's architecture must remain self-hosted and air-gapped capable.
