## Narrative

Core frame: agents run the **inner loop** (investigate → implement → verify); engineers own the **outer loop** — Quality (checks/evidence), Verdict (ship/block/redirect), Answerability (explain why). Model = engine; harness = car; factory = loops at scale. Humans stay in constraints / sampling / audit / ownership loops — not the inner execution loop. Hidden costs: cognitive surrender, cognitive debt (Anthropic RCT: −17pp comprehension), orchestration tax. Taste + accountability scale the factory. **CCC brief** — federation `/goal` + harness canon. Aligns with K151 reasoning-effort steal and K150 skill-atrophy AMA.
