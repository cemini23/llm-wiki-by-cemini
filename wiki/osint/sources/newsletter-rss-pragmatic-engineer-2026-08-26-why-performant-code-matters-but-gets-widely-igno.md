## Narrative

PE interview with Casey Muratori on why performant code is systematically ignored despite user-visible cost. For agent harnesses, the steal is cultural: verify loops, sandbox spin-up, and tool fan-out burn wall-clock and tokens the same way slow product code burns UX. Awareness for CCC — prefer measured harness latency over feature sprawl. No prod wire.
