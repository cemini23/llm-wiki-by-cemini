## Narrative

ArchBench is presented as the first unified platform for benchmarking LLM (and LLM-based coding-agent) capabilities on software-architecture tasks. The motivation is a coverage gap: LLM benchmarks have progressed from snippet-level function generation to repository-level issue resolution (e.g. SWE-bench), but overwhelmingly target implementation correctness. Architectural tasks — modularization, dependency management, decision records, traceability — remain under-specified and hard to compare across models, even though architectural flaws compound silently and dominate long-term maintenance effort. A cited multivocal literature review confirms rigorous testing of GenAI architecture outputs is typically missing and architecture-specific datasets are scarce.

The platform pairs a Python CLI with a public web leaderboard (sabench.com). The CLI implements a three-stage pipeline: **Download** (datasets auto-fetched from GitHub/Zenodo/HuggingFace and cached), **Inference** (prompts assembled from task templates, dispatched via a uniform provider interface to OpenAI/Anthropic/Qwen/Gemini, with full trajectory logging of prompts, raw responses, token usage, and latency), and **Evaluation** (task-appropriate metrics plus optional LLM-as-judge). A plugin architecture makes each task a self-contained module — dataset loader, prompt templates, response parser, evaluation logic — so new tasks and results are contributed via pull request without core changes, following the SWE-bench community model.

ArchBench ships with five tasks drawn from published research: ADR Generation (1000 architectural documents; ROUGE/BLEU/METEOR/BERTScore), Architectural/Serverless Component Generation (Wonderless dataset, test pass rate + CodeBLEU), Dynamic Service Generation (IoT services, CodeBERTScore), Traceability Link Recovery (ArDoCo benchmark, precision/recall/F1 via set matching), and Microservice Generation (4 Java projects, 12 microservices, test suites + complexity). Task selection follows Esposito et al.'s taxonomy of GenAI applications in software architecture; the platform is designed to grow toward full taxonomy coverage.

**Cemini relevance**: ArchBench's plugin-per-task design and standardized download/inference/evaluation pipeline with trajectory logging are a clean reference pattern for evaluating any coding/architecture-advisor agent in the Cemini stack — and for benchmarking the conductor's own architectural-reasoning outputs reproducibly.
