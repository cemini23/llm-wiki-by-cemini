## Narrative

Academic red-teaming paper proposing **ClawSafety**, a benchmark suite for evaluating prompt-injection resistance in personal LLM agents (OS-level assistants running with elevated privileges — file access, shell execution, browser control, credential vaults). The authors argue that existing LLM safety evaluations are inadequate for the agent setting because they test models in isolated chat, where refusal training is strongest; once the same models are placed behind an agent scaffold with tool calls, the attack surface shifts to **injected instructions arriving through third-party content** (skill manifests, incoming emails, web pages the agent renders). ClawSafety constructs 120 adversarial test cases organized as 5 harmful-action domains × 3 injection vectors × 8 cases each, then runs 2,520 sandboxed trials across 5 frontier LLMs (Claude Sonnet 4.6, GPT-5.1, Gemini 2.5 Pro, DeepSeek V3, Kimi K2.5) on 3 agent scaffolds (OpenClaw, Nanobot, NemoClaw).

The empirical picture is unflattering for the agent-scaffold stack. Attack success rate (ASR) averaged across models and scaffolds ranges from ~40% (Sonnet 4.6, the strongest) to ~75% (GPT-5.1, the weakest), with a clear **trust-level gradient** across injection vectors: skill-manifest injections succeed ~69.4% of the time, email injections ~60.5%, web-content injections ~38.4% — agents treat skill-layer text as operator-authoritative and route around safety training. Scaffold choice matters almost as much as model choice (8.6pp swing across OpenClaw/Nanobot/NemoClaw for fixed model), which means "safe LLM + safe scaffold" is not a solved additive problem. The paper also identifies an **imperative-vs-declarative framing boundary**: refusals hold on imperative ("delete all files") but collapse on declarative or role-played framings ("the user's preference is that files in /tmp be cleaned"). Bright spots: Sonnet 4.6 reaches 0% ASR on credential-forwarding and destructive-action categories, suggesting the high-severity tail can be suppressed by the model alone when training targets it; no other frontier model hits 0% on either category.

**Cluster misfit flag**: this paper was tagged `crypto` but the crypto content is a single phrase — "cryptocurrency wallets" appears once in OpenClaw's capability list as an example of sensitive credential storage. There is no blockchain work, no smart-contract analysis, no on-chain evaluation, no tokenomics. The real cluster is **llm-agents / agent-safety / red-teaming**. Recommend removing `crypto` from clusters in Phase 2; retain `llm-agents` as primary. Paper quality is solid — methodology is reproducible, scaffold selection is defensible (OpenClaw is the reference personal agent, Nanobot and NemoClaw are plausibly-chosen alternatives), and the ASR numbers are calibrated with CI. Main limitations: static test corpus (no adaptive attacker), sandbox may understate real-world blast radius, model list is current-gen only so results will age fast. Flag: **rigorous-benchmark**, **agent-safety-primary**, **not-crypto**.

## Key findings

- **ClawSafety benchmark**: 120 adversarial test cases = 5 harmful-action domains (credential exfiltration, financial redirection, destructive file ops, privacy leak, unauthorized external actions) × 3 injection vectors (skill manifest, email body, rendered web page) × 8 cases per cell. 2,520 total sandboxed trials across 5 models × 3 scaffolds × 120 cases (with repeats).
- **Headline ASR**: Claude Sonnet 4.6 ≈ 40% attack success rate (best), GPT-5.1 ≈ 75% (worst); Gemini 2.5 Pro, DeepSeek V3, Kimi K2.5 cluster in between. No frontier model below 40% ASR on any scaffold.
- **Trust-level gradient across injection vectors**: skill-manifest ASR 69.4% > email 60.5% > web content 38.4%. Agents treat skill/operator-layer instructions as authoritative, undoing chat-level safety training.
- **Scaffold-dependent safety**: 8.6pp ASR swing across OpenClaw/Nanobot/NemoClaw holding model fixed — scaffold design (tool-call wrapping, skill-trust model, web-render sandboxing) is roughly as load-bearing as the underlying LLM.
- **Framing asymmetry**: imperative-command injections ("delete all files") hit refusal reliably; declarative or role-played framings ("the user prefers that /tmp be cleaned") bypass refusal training on every model tested.
- **Bright spots**: Sonnet 4.6 reaches 0% ASR on credential-forwarding and destructive-action categories specifically — suggests high-severity tail is suppressible via model-level training when targeted. No other tested model hits 0% in either category.
- **Crypto-cluster relevance**: essentially zero. Single phrase ("cryptocurrency wallets") in OpenClaw capability list; no blockchain, no smart-contract, no on-chain content. **Cluster assignment misfit.**

## Snippets

- **Abstract** — "Personal AI agents such as OpenClaw execute with elevated privileges on users' local machines, where a single successful prompt injection can leak credentials, redirect financial transactions, or destroy files. We introduce ClawSafety, a benchmark of 120 adversarial test cases spanning 5 harmful-action domains and 3 injection vectors, and we evaluate 5 frontier LLMs on 3 agent scaffolds across 2,520 sandboxed trials." — thesis.
- **§3 (benchmark construction)** — "Each injection vector corresponds to a distinct trust level in the agent's input surface: skill manifests, emails, and rendered web pages. We find that attack success rates vary systematically with this trust level, with skill-manifest injections succeeding 69.4% of the time versus 38.4% for web content." — trust-gradient headline.
- **§4 (model results, Table 1)** — "Claude Sonnet 4.6 attains the lowest mean ASR (40.3%), followed by Gemini 2.5 Pro (53.1%), Kimi K2.5 (58.7%), DeepSeek V3 (64.2%), and GPT-5.1 (74.9%)." — model ranking by ASR, averaged across scaffolds and vectors.
- **§4.3 (scaffold effects)** — "Holding the model fixed, ASR varies by up to 8.6 percentage points across OpenClaw, Nanobot, and NemoClaw, indicating that scaffold design materially shifts the attack surface." — scaffold-dependence finding.
- **§5 (framing analysis)** — "Declarative or role-played framings bypass refusal training that holds against imperative instructions; an injection phrased as 'the user's preference is that …' is ~2× more likely to succeed than the same content phrased as a direct command." — imperative-vs-declarative boundary.
- **§6 (bright spots and limits)** — "Claude Sonnet 4.6 achieves 0% ASR on credential-forwarding and destructive-action categories. No other evaluated model reaches 0% in either category." — severity-tail suppression finding.
