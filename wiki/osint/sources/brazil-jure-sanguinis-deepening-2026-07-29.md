## Narrative

**[RETRACTED / overstated]** Prior implication that CRC Nacional intermediation reliably yields **inteiro teor** for foreign residents. CRC **excludes** inteiro teor (LGPD); path is usually **direct cartório** (email/WhatsApp) + *requerimento* / direct-interest proof. National portals sell **breve relato** / Busca Nacional; SP **e-Protocolo** is a parallel track.

Practice overlays: São Paulo / Belo Horizonte still reject electronic docs / e-Apostilles — physical apostille chain dominates. CNN via `deest.mj.gov.br/ecertidao/` with **all name variants**. Certidão national fields tightened under CNJ Prov. **63/2017 → 149/2023** (CPF, DNV, gender-neutral *filiação*, Lei **13.484/2017** *naturalidade*).
