## Narrative

Symbol + wordmark system for Atto (Italian civil-record DIY organizer). Primary territory: **Document / folio stack** (24/25 rubric). Backup: abstract geometric **A** (19/25). Reject: vault/lock, family tree/DNA, Italian flag/passport kitsch, wordmark-only as dock icon.

**Architecture:** Dec / Discord / notification badges use the folio symbol alone; site, Gumroad, and UI header use symbol + serif wordmark. Wordmark-only fails Apple HIG at small sizes; bare “A” is scalable but generic.

**Palette (shared base):** Vellum `#F5F2EB` · Slate ink `#1A1C20` · accent A terracotta `#C25946` **or** accent B cypress `#4A6B53`. Operator running both accents as a visual A/B before lock.

**Type:** Serif editorial wordmark (Playfair / GT Alpina / Garamond-class) + geometric sans for dense Tauri UI (SF Pro / Inter-class). Avoid neon/cyber (ATTO Tech trademark collision risk).

**Must-not:** Gavels, scales, columns, eagle seals; Repubblica Italiana emblem / passport burgundy mimicry; DNA / sepia trees / fingerprints; cloud “magic” nodes; baked-in rounded corners on macOS icon PNG (system applies squircle).

**Ship assets (lean):** 1024 PNG app icon (opaque bg, no baked corners) · SVG lockup · Gumroad 1280×720 · Discord server 512×512 (circle-safe). Defer dark-mode icon, Nitro banners, Linux adaptive XML.

**Vendor path:** Founder locks geometry + hexes → freelancer ~$300–800 for bezier / Liquid Glass / optical align.

## Snippets

> Primary Recommendation: Territory 1 (Folio Stack). It achieves perfect scores in UPL safety… macOS native feel, and pure legibility at small sizes.

> Accent Color (Tuscan Terracotta or Faded Cypress): A muted, earthy red (e.g., #C25946) or a deep olive green (e.g., #4A6B53).

## Dead Ends

- Wordmark-forced into squircle → weak negative space; illegible at 40×40.
- Literal parchment texture / thin hairlines → die at 16px menu bar.
- Tricolor flag as brand primary → tourism/food kitsch + hard UI balance.
