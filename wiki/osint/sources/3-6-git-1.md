## Narrative

An evaluation of **36 external resources** (GitHub repos, papers, tools, skill packs) for Cemini's agentic ecosystem. Key items: (a) **ToxicSkills** — identified as an active threat vector in the Agent Skills ecosystem (malicious SKILL.md packs that can steal credentials or exfiltrate data), warranting explicit countermeasures; (b) **OpenSandbox** — Firecracker-based microVM sandbox for untrusted skill execution; (c) **ModelAudit** — model-weights audit tool to detect tampered / trojaned weights; (d) **Paperclip** and **Lobster** — smaller tools in the agent-infra space.

The ToxicSkills warning is substantive: the document argues that adopting the Anthropic Agent Skills ecosystem without a skill-vetting layer is a concrete security risk, and proposes OpenSandbox + ModelAudit + skill-vetting protocol as the defensive stack. This is one of the more security-literate internal documents.

Similar format to other 3/5–3/18 architect's memos — explicit verdicts, engineering estimates, license notes. Value as a security-hardening blueprint is high. Treat as internal artifact, not research.
