## Narrative

LLMs are strong at competitive programming (CP), but existing methods evaluate in **single-attempt settings**, overlooking iterative refinement. Prior open-source self-correction work (e.g. Reflexion-style loops by Shi et al. 2024, Li et al. 2025) iterates until a solution passes all *public* test cases — but public tests are a sparse proxy for the hidden private distribution, so the loop stops at **false positives** (passes visible checks, fails unseen data). As a purely test-time method, Reflexion also depends entirely on the base model's intrinsic refinement ability, with no training to optimize the refinement process itself.

**RefineRL** addresses both gaps with two components. (1) **Skeptical-Agent**: an iterative self-refinement agent with local execution tools that validates generated solutions against public CP test cases, but maintains a **consistently skeptical attitude** — it enforces rigorous self-refinement *even when validation suggests correctness*, using a fine-grained agentic workflow keyed to different judging statuses. (2) **Self-Refinement RL**: an RL method that explicitly incentivizes self-refinement using only standard **RLVR data** (problems paired with verifiable answers), constructing a training set from the model's own skeptical-refinement trajectories and a new **squared-incentive reward function** — moving beyond static prompt engineering. Experiments on **Qwen3-4B and Qwen3-4B-2507**, using only **4.5K HardTest problems**, show the trained compact 4B models with the Skeptical-Agent **outperform much larger 32B models** and **approach the single-attempt performance of 235B models** — strong evidence that self-refinement is an under-explored axis for scaling LLM reasoning.

**Cemini relevance**: self-refinement RL for code generation — directly applicable to improving agentic coding/strategy-implementation quality, and the "skeptical validation against weak signals" pattern transfers to any agent that must avoid false-positive confidence on sparse feedback.
