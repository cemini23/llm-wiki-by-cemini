## Narrative

TSAG introduces a rigorous evaluation methodology for measuring LLM agents' reasoning capabilities on quantitative financial tasks. The framework operates as a Tool-Augmented RAG system: an LLM agent parses a natural-language financial question, selects appropriate computational tools from a library, delegates computation to those verifiable tools, and synthesizes a response from tool outputs.

### Methodology

TSAG isolates three core agent capabilities independent of live data noise:
1. **Query parsing** — correctly interpreting what computation is being asked for
2. **Tool selection** — choosing the right computational tool(s) from the library
3. **Parameter extraction** — correctly extracting parameters (ticker, date range, indicator) from natural language

The benchmark: 100 financial questions at varying brevity levels, each requiring specific tool invocations with verifiable outputs. Questions span time-series analysis tasks: trend detection, volatility computation, correlation analysis, forecasting, anomaly detection.

### Evaluation metrics

| Metric | What it measures |
|--------|-----------------|
| Return Rate (RR) | Successful end-to-end execution |
| Match Accuracy (MA) | Correct tool selection vs. ground truth |
| LLM-assessed Accuracy (LA) | Response quality (DeepEval judge) |
| Hallucination Rate (HR) | Factual errors not grounded in tool outputs |
| Seconds Per Query (SPQ) | Latency |
| Mean Prediction Error (MPE) | Consistency across runs |

### Key results

Top agents demonstrated near-perfect tool orchestration:

| Agent | Match Accuracy | Hallucination Rate | LLM Accuracy |
|-------|---------------|-------------------|--------------|
| GPT-4o | 1.00 | 0.02 | — |
| Qwen2 7B | 1.00 | — | 0.66 |
| DeepSeek-V3 | evaluated | — | — |
| Llama 3.x | evaluated | — | — |

Baseline (no-tool LLM): zero Match Accuracy, negligible LLM Accuracy, high Hallucination Rate — confirming TSAG's necessity for grounded quantitative Q&A.

Deterministic generation (Temperature=0.0) vs. stochastic (Temperature=1.0) comparison provided insights into consistency tradeoffs.

### Why this matters for Cemini

TSAG directly evaluates the exact pattern Cemini's analyst pipeline uses: LLM → tool delegation → computational verification → response synthesis. The benchmark provides:

1. **Calibration targets** — GPT-4o's 1.00 Match Accuracy and 0.02 Hallucination Rate establish a performance ceiling for tool-augmented financial Q&A
2. **Model selection data** — Qwen2 7B achieving Match Accuracy 1.00 at 7B parameters demonstrates that tool-use competence doesn't require frontier-model scale
3. **Methodology reuse** — the evaluation framework (DeepEval-based, tool-ground-truth-validated) can be adapted for Cemini's analyst prompt builder calibration
4. **Temperature insights** — deterministic vs. stochastic comparison informs analyst deployment configuration

The paper confirms rather than refutes the tool-augmented paradigm — it's not architecturally novel, but its empirical methodology is directly reusable for Cemini's analyst calibration.

Code released publicly per abstract.
