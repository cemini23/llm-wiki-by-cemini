## Narrative

This post announces a set of free genealogy and historical-geography tools for Italy. The centrepiece is an interactive historical atlas that covers 9,869 municipalities from 1796 to 2026.

The interface takes a town name and a year. It returns four facts:

1. Which sovereign regime governed that territory.
2. Which historical province held jurisdiction.
3. Which modern comune the place belongs to today.
4. Which State Archive or Diocesan Archive holds the vital records.

The design rule the author emphasises most: **the atlas never invents a coordinate.** A place is resolved through jurisdiction and archive, not through a guessed point on a map. The model reads the year at 1 July.

Five standalone tools went live. All are free, with no accounts and no API keys. Two are named in the retrieved text:

- **Historical Atlas** (`/atlas/`) — resolves a town and year in the 1796–2026 range to regime, historical province, modern comune, civil registration series, and State Archive.
- **Parrocchie & Dioceses** (`/parrocchie/`) — identifies the overseeing Roman Catholic diocese, the cathedral, and the Archivio Storico Diocesano, with direct BeWeB links, for baptismal and marriage acts that predate civil registration.

The remaining three tools are not described in the retrieved text.

The relevance here is methodological, and it matches an existing workspace position. For historical family research, an agent should emit a place and year and let a jurisdiction model resolve the boundary. It should not emit a coordinate it cannot support. That is the same contract recorded for the earlier historical-jurisdiction atlas work.
