## Narrative

Eureka compiles a long-horizon task into a dynamic **obligation graph** with explicit acceptance semantics, then forms specialized Macro-Agents (state, memory, operators, tools, verifiers, local topology) via receding-horizon planning. Recurring bottlenecks trigger cost-benefit-gated **governed evolution** of the local architecture. Reported system numbers: 170/170 recursive long-horizon tasks, 3,948 acceptance certificates, no observed uncertified acceptance; median model-input context 9,490 → 4,005 tokens; 65.38% of repeated computation avoided on 12,000 dependency-update tasks; 16,000 concurrent executions serializable.

**Concrete claim `[TENTATIVE]`:** capability of a scientific agent depends not only on the underlying model but on whether an appropriate agent architecture can be formed and maintained for the task's cognitive structure.
