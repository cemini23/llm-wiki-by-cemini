## Narrative

A dataset + harness for training agents to answer **multi-hop** questions by walking a knowledge graph (Wikidata).

### What is released

- **10,235 solving traces.** Questions are generated by SELECT/EXPAND operators that hide named entities behind nested conditions, so the answer cannot be read off one fact. A question is certified only when the direct target set is a singleton and removing any constraint breaks it (|T_{B\{c}}| ≥ 2).
- **A Recursive Language Model (RLM) harness.** Thirteen graph functions (search_entity, claims, edges, …) are called **from a persistent Python REPL**, with batching and `llm_query` sub-calls. Snapshot: frozen Feb-2026 Wikidata, ≈48M items, 262M facts.

### The headline finding

**A persistent-Python-state harness beats direct tool calling.** Over 100 questions:

| Model | Direct | RLM harness |
|-------|--------|-------------|
| gpt-6-luna | 49 → | 61 correct |
| Qwen3.8-27B (1×H100) | 60 → | 74 correct |

Multi-hop subset: gpt-6-luna 9 → 19 / 50; Qwen3.8-27B 20 → 28 / 50. Target reached 17 → 35 and 27 → 39.

### Why it matters here

The reusable claim is architectural: **give the agent a real interpreter with persistent state, not a stateless tool-call loop.** That is the same lesson behind the wiki's `agent-tool-use-verification` thread and the CCC harness work. The Wikidata traces themselves are a public training/eval set for graph-search agents.

**No explicit license stated** for the dataset. Harness traces the `PrimeIntellect-ai/nano-rlm` repo.
