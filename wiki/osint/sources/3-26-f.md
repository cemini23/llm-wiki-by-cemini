## Narrative

Internal capital-allocation planning brief: how a solo CeminiSuite developer should spend a fixed $10K over a 2-year IP-build runway. Structured as 7 costed questions plus a 3-point synthesis.

**Hardware (Q1–Q2, Q5).** Recommends the **Mac Studio M4 Max** (16-core CPU / 40-core GPU / **64GB** unified memory, ~$3,299) over the Mac Mini M4 Pro and over RTX 4090/5080 mini-PCs. Rationale: local LLM inference is memory-bandwidth-bound — the Studio's 546 GB/s drives 14B models (DeepSeek-R1-14B / Qwen-2.5-14B at Q4 ≈ 50 tok/s) while NVIDIA's 16–24GB VRAM ceiling collapses throughput up to 50x once the LLM + 5-agent KV cache + TorchRL buffers spill to system RAM. 64GB is the "sweet spot" — peak footprint 35–45GB (macOS ~8GB, 30-container stack ~10–12GB, 14B model ~9GB, KV cache 6–10GB), leaving a ~19GB buffer; 96/128GB adds $800–1,000 with zero token-speed gain. Studio also wins on 24/7 thermals/acoustics (sub-30 dBA vs the Mini's 45+ dBA throttling) at ~$9.30/mo Florida power.

**Burn rate (Q3, Q6).** A "premium" stack runs ~$344/mo (over budget); the "optimized" stack hits **$184/mo** by dropping Polygon.io ($199) for **ThetaData ($40)** + Finnhub free tier, and replacing usage-based Claude API with the **Claude Max 5x subscription ($100/mo)** — claimed ~36x cheaper for agentic loops since web-interface cache reads are unmetered. Free alternatives flagged: Databento, EODHD, Quiver Quantitative, OpenInsider, FRED, Kalshi/Polymarket APIs.

**Topology (Q4).** Strict hub-and-spoke: production trading core stays pinned to **Hetzner VPS** (static IP, sub-20ms broker latency); LLM inference / TorchRL / backtesting offload to the local Mac Studio, bridged via a **Tailscale** WireGuard mesh — acceptable for Kalshi/swing trades, fatal for HFT.

**IP-sale ROI ranking (Q7).** Highest to lowest: legal/license compliance (a single GPL/AGPL dep can kill an acquisition) > documentation/presentation quality > clean market data > additional data sources > AI dev tools > hardware (zero transferable value). Synthesis actions: migrate Docker to OrbStack, switch to Claude Max subscription, add anti-copyleft CI/CD gates (pip-licenses, TruffleHog).
