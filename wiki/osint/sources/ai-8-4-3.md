## Narrative

LEAPS is an Alibaba (Taobao & Tmall Group) production system that augments traditional e-commerce search with LLM-powered plugins at both ends of the retrieval pipeline. Deployed since August 2025, it serves hundreds of millions of monthly users.

### Architecture: "Broaden-and-Refine"

The core insight is that conversational queries (e.g., "linen blazer for beach wedding, 500-800 yuan, no black, no large patterns") create a dilemma for traditional search: enforcing all constraints produces zero results, while relaxing them produces decision overload. LEAPS solves this with two plugins:

1. **Upstream — Query Expander** ("Broaden"): An LLM that translates complex natural-language queries into multiple complementary keyword combinations. Uses a novel three-stage training strategy:
   - Stage 1: Inverse data augmentation (generating synthetic complex queries from product pairs)
   - Stage 2: Posterior-knowledge supervised fine-tuning (grounding expansions in actual retrieval results)
   - Stage 3: Diversity-aware reinforcement learning (rewarding query sets that maximize distinct product coverage)

2. **Downstream — Relevance Verifier** ("Refine"): An LLM that re-ranks retrieved candidates using chain-of-thought reasoning over multi-source data (OCR text, reviews, attributes). Filters noise from the broadened query results.

### Key properties

- **Non-invasive**: Plugs into existing search architecture without disrupting optimized short-query retrieval
- **Low-cost integration**: Works across diverse backends
- **Production-validated**: Full deployment on Taobao AI Search since August 2025

### Cemini relevance

The paper is cited from `@concepts/llm-agent-systems.md` and `@concepts/market-microstructure.md`, but the direct trading relevance is limited. The transferable patterns are:

1. **Three-stage RL training strategy** (inverse augmentation → supervised grounding → diversity RL) — applicable to training the MAPPO ensemble on synthetic market scenarios before live deployment
2. **Broaden-and-Refine plugin architecture** — the two-stage LLM pipeline (expansion + verification) is a reusable agent orchestration pattern for financial research queries
3. **Non-invasive integration** — the "attach to existing pipeline without disruption" philosophy parallels how SAE middleware (`@sources/4-11-crypto-re.md`) attaches to the Cemini execution pipeline

**Bottom line**: Low direct trading relevance. Worth citing for the RL training methodology and plugin architecture pattern, not for the e-commerce search domain.

## Snippets

### S1 — Core problem statement

> "Users are often caught in a dilemma: precise natural language descriptions frequently trigger zero-result scenarios, while the forced simplification of queries leads to decision overload from noisy, generic results. To tackle this challenge, we propose LEAPS (LLM-Empowered Adaptive Plugin for Taobao AI Search), which seamlessly upgrades traditional search systems via a 'Broaden-and-Refine' paradigm."

### S2 — Three-stage training

> "A novel three-stage training strategy—inverse data augmentation, posterior-knowledge supervised fine-tuning, and diversity-aware reinforcement learning—to generate adaptive and complementary query combinations that maximize the candidate product set."

### S3 — Non-invasive architecture

> "Its non-invasive architecture preserves established retrieval performance optimized for short-text queries, while simultaneously allowing for low-cost integration into diverse back-ends. Fully deployed on Taobao AI Search since August 2025, LEAPS currently serves hundreds of millions of users monthly."
