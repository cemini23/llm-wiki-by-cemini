## Narrative

AutoMOOSE is an open-source agentic framework that orchestrates the full lifecycle of phase-field materials simulations in the MOOSE multiphysics finite-element environment from a single natural-language prompt, using a five-agent pipeline (Architect, Input Writer, Runner, Reviewer, Visualization) and an MCP server exposing the workflow as ten tools. The work is materials-science finite-element simulation tooling — its domain (copper grain-growth phase-field modeling) has no transfer path to Cemini's financial/OSINT trading-stack research agenda.
