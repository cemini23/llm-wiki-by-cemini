## Narrative

RegenHarness is an evidence-gated robot harness. The paper separates a model proposal, a controller stop, and a verified task completion. A commit to trusted task state waits on an identity-bound and version-bound gate. The paper says it checks the original user goal before it reports completion.

The paper calls this an evidence-gated recursive self-improvement protocol for embodied agents. That claim is a citation. It is not a license to change local skills.
