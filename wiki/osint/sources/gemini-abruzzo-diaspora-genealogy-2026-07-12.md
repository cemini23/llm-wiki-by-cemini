## Narrative

K160 **family-tree** methodology for **Abruzzo Citeriore** lines spanning Colledimacine, Montenerodomo, Torricella Peligna, and post-war **Australian** + **missionary India** diaspora vectors. Digital OSINT hits a hard wall for mid–late 20th-c subjects: Italian civil records post-1920 are sealed; Australian naturalization packets and diocesan *fascicoli* require offline petition.

### Archival fracture (20th c)

| Era / jurisdiction | Repository | Access pattern |
|--------------------|------------|----------------|
| Pre-1920 Italy civil | Antenati / ASC Chieti | Parish + Restoration-era browse |
| Post-1920 Italy | *Comune* Stato Civile | *Copia integrale* + ID + descent proof; PEC where offered |
| WWI veterans | Ministero della Difesa — Ordine di Vittorio Veneto | *Foglio matricolare* + honor roll for *mutilati* |
| Secular clergy | Diocesi di Chieti-Vasto archivio storico | *Fascicolo personale* per priest |
| Missionary exit | PIME / Saveriani central archives (Rome/Parma) | If priest left diocesan structure post-*Fidei Donum* |
| Australia migration | NAA RecordSearch | Alien Registration (A-file) + Naturalization packet |
| NSW vitals | NSW BDM historical index | Death index → parental names on certificate order |

### Methodology steals (no names on wiki)

1. **Military honor as chronological lock** — Cavaliere di Vittorio Veneto (1968+) proves WWI service survivor into late 1960s; unlocks matriculation request.
2. **Large sibling-count prior** — confirmed 11-child *stato di famiglia* scales reconcile obituary informant omissions (distinct brothers vs nickname confusion).
3. **Ecclesiastical political friction → missionary dispatch** — 1964 municipal list against DC (*Scudo Crociato*) explains *Fidei Donum* India exit without PIME digital index hit.
4. **Homonym quarantine** — high-profile namesakes (pharmacy guild presidents, Ontario branches) must be isolated before NAA queries.
5. **Swiss guest-worker negative results** — algorithmic false positives (footwear brands, IBM researchers) require surname + comune anchor.
6. **Italian cemetery concession recycling** — negative cemetery index ≠ proof of non-burial; temporary concessions expire.

### Human action list (operator)

Critical path offline requests (detail + private names in family sprint):

- NAA: Alien/Naturalization search keyed on **arrival year + birth year** from diaspora obituary
- Comune Colledimacine: historic *stato di famiglia* for patriarchal household
- Chieti diocese: *fascicolo personale* for Montenerodomo parish priest tenure
- Ministero della Difesa: WWI matriculation for *mutilato* + Vittorio Veneto honor
- ANMI Rome: membership dossier for diaspora association president
- *L'Araldo Abruzzese* bound volumes 1974–1976 for missionary departure notice
