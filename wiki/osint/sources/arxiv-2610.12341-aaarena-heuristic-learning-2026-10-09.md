## Narrative

AAArena is 12 adversarial games and 1,920 archived human programs. Agents read rules, pick opponents, read replays, and edit the game program. Model weights stay fixed.

The paper says Opus 5.5 with Claude Code earns 6 gold medals. No tested setup tops the other 6 human ladders. Harder rule text lines up with weaker play.

Weights stay fixed, so this is not a training wire. No rule change. The named GitHub repo is not installed.
