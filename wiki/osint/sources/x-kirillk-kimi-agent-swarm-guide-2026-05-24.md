## Narrative

Promotional-but-structured explainer of **Moonshot AI Kimi Agent Swarm** (`https://www.kimi.com/agent-swarm`): K2.6 decomposes one user prompt into up to **300 parallel sub-agents** and **4,000 coordinated steps**, then a **central coordinator** synthesizes deliverables (reports, spreadsheets, landing pages, CV batches).

Contrasts with **Anthropic Claude Agent Teams** (~4–6 practical agents, peer-to-peer mailbox, terminal / Claude Code coding workflows).

**Claimed use cases** [TENTATIVE — marketing examples]: 100 tailored CVs from one CV + 100 listings; 40-paper literature review; 30 Google Maps stores → landing pages; tabloid covers; astrophysics paper → report + dataset + charts.

**Cemini relevance:** reference architecture for **scatter-gather at extreme parallelism** on research/content tasks — **not** a trading-stack adoption candidate (web UI, third-party coordinator, no CLOB integration). Conductor + librarian already cover multi-step routing; see concept page for fit matrix.
