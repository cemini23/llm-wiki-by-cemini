## Narrative

Internal Q&A-format audit structured around 7+ numbered questions covering the Cemini MAPPO ensemble's observation space, heterogeneous-agent handling, curriculum, regime overfitting, credit assignment, and institutional IP-readiness. The report is explicitly calibrated to a single CPU-only 128GB Hetzner VPS solo-dev stack with IP-sale framing throughout.

Core recommendations: (1) Extend the 28-feature space to 31 features by adding Order Flow Imbalance (OFI), a retail-vs-institutional cross-venue share proxy (KVSI-style), and a Hurst Exponent via vectorized Polars downsampled log-variance ratio. Standard TA (RSI/MACD) framed as "zero-alpha". (2) Heterogeneous MAPPO handled via TorchRL `group_map` + Unified Action Space with MaskedCategorical (not parameter-sharing); cites a known TorchRL bug triggered only on CUDA — so CPU-only avoids it. (3) Curriculum: Reinforced Adaptive Staircase (RASCL) with UCB-based dynamic sampling over TimescaleDB continuous-aggregate regime partitions, LangGraph-orchestrated, with catastrophic-forgetting mitigation via RLS-style forgetting factor. (4) Regime-overfitting: explicit hierarchical regime gating (RegimeFolio 2025 pattern) + Quantile Advantage Estimation (QAE, late-2025) replacing standard PPO mean baseline with group-wise α-quantile baseline to bound entropy change in both directions.

Relevant to Cemini as the working research reference behind the observation-space and training-loop design. Honest limits: consulting/audit style with per-question "IP valuation" preamble — cherry-picks 2025-2026 papers (QAE, RASCL, RegimeFolio) without critical comparison; several citations appear in boilerplate footnotes; the "32 hours / 40 hours" effort estimates aren't grounded in prior Cemini engineering tickets. The prescribed architecture is internally coherent but unbenchmarked against Cemini's actual data.

## Key findings

- Prescribed 3 new observation features: OFI (Polars rolling bid/ask vol diff), cross-venue retail-vs-institutional proxy, Hurst exponent (downsampled log-variance ratio) — 28 → 31 feature space.
- RSI/MACD framed as "zero-alpha" by sophisticated buyers — argument for LOB-based microstructure features.
- Heterogeneous MAPPO handled via TorchRL `group_map` + Unified Action Space + MaskedCategorical (not shared parameters); explicit sequential update scheme (HARL pattern) over vanilla MAPPO.
- Quantile Advantage Estimation (QAE) replaces PPO's mean baseline with α-quantile baseline — bounds one-step entropy change, prevents "100% WAIT" collapse and panic-trading explosion.
- RASCL curriculum with UCB sampling + TimescaleDB continuous-aggregate regime partitions + LangGraph Redis-pubsub orchestration.
- Explicit external regime classifier ("Devil's Advocate 5-agent LLM debate") publishes to `intel:regime` Redis stream, one-hot injected into TensorDict.
- Known TorchRL MaskedCategorical CUDA bug noted — CPU-only constraint sidesteps it.

## Snippets

- **Q1** — "Standard features like Relative Strength Index (RSI) and Moving Average Convergence Divergence (MACD) are deemed 'zero-alpha' metrics by sophisticated buyers."
- **Q2 TorchRL** — "`group_map = {'momentum': ['agent_mom'], 'reversion': ['agent_rev'], 'volatility': ['agent_vol'], 'macro': ['agent_mac'], 'contrarian': ['agent_con']}`. This forces TorchRL to maintain separate TensorDict instances rather than attempting a vectorized stack that would crash due to shape mismatches."
- **Q3 RASCL** — "Adaptive curriculum schedules have been shown to reduce average optimality gaps from 19.35% down to 10.46% in complex sequential decision-making tasks."
- **Q4 QAE** — "QAE mathematically induces a two-regime gate inside the policy gradient update itself: on hard or highly uncertain queries, it reinforces rare successful actions, while on easy queries, it strictly targets and suppresses remaining failures."
