## Narrative

MOOSEnger is a tool-enabled, domain-specific AI agent that translates natural-language requests into runnable MOOSE multiphysics-simulation input files (Hierarchical Input Text `.i` files), combining RAG over MOOSE documentation with a deterministic input-precheck pipeline and a runtime-in-the-loop correction loop that raises the execution pass rate to 0.90 versus 0.06 for an LLM-only baseline. As a materials-science finite-element simulation agent, its domain has no application path to Cemini's financial/OSINT trading-stack research agenda.
