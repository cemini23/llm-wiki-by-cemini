## Narrative

RLAE (arXiv 2506.04309, May 2025) reformulates LLM ensembling as a reinforcement learning problem. Existing ensemble methods use **fixed weighting strategies** that cannot adapt to the dynamic, context-dependent strengths of different models — ranker-based ensembles (e.g. LLM-BLENDER) need quadratic pairwise comparisons and operate only at response level; token-level heuristic ensembles (GAC, DEEPEN) fuse probability distributions but ignore broader context. RLAE casts ensembling as a Markov Decision Process: the **state** is the input prompt plus generated response history, the **action** is the per-model ensemble weight vector (softmax over models, summing to 1), and the **reward** corresponds directly to final output quality. To balance granularity and cost it uses a **span-level** strategy — weights stay fixed across L consecutive tokens, cutting decision points from H to ⌈H/L⌉ — and projects each model's probability vector into a unified vocabulary space to handle tokenizer mismatch.

Two instantiations are provided. **RLAE_PPO** (single-agent): one RL agent controls all model weights via PPO with a DeBERTa-V3-Large (~400M) policy/value network. **RLAE_MAPPO** (multi-agent): each LLM is controlled by an independent RL agent that emits a scalar logit, logits are concatenated and softmaxed, and agents share a centralized critic — decomposing the joint action space, letting each agent specialize, and scaling cleanly as base models are added.

Evaluation spans seven benchmarks (MMLU, ARC-C, TriviaQA, GSM8K, PIQA, GPQA, MBPP) ensembling 5 comparable ~7-8B base models (Llama-3.1, Qwen-2, Qwen-2.5, Mistral-7B-v0.3, OpenChat-3.5). **RLAE_MAPPO reached an average score of 70.1 on the primary 3-LLM set**, beating all base models and the PAIRRANKER/GAC/DEEPEN baselines, with improvements up to **3.3 accuracy points** over prior ensemble methods. It also generalizes across tasks without retraining and achieves lower inference latency (no reward/supervision signal needed at inference).

**Cemini relevance**: RLAE is directly relevant to the conductor and multi-model orchestration — it shows how an RL agent (single- or multi-agent MAPPO) can *dynamically* route/weight across multiple LLMs by context rather than using static rules, the exact problem a conductor faces when blending model outputs.
