## Narrative

World Action Agent is a multi-agent harness for a robot. Vision-language models pilot the robot with basic tools inside a visual workspace. Contact views show the scene around the current interaction. Action rehearsal turns a move into a proposal that the agent can preview before execution.

No repo is in the PDF. This is **not a product**. No robotics install.
