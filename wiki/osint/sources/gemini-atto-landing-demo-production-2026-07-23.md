## Narrative

Production brief for $299 local vault demos: 8–12s silent hero loop, 60–90s narrated demo, 10 vertical short concepts, fictional **Rossi** sample lineage, and a hard “what NOT to show” list.

**v1 lead asset recommendation:** high-fidelity **static UI + silent GIF/WebP tiles** — not a large autoplay narrated hero. Narrated demo is bottom-of-funnel and last in production order.

**Forbidden visuals:** Prenot@Mi scrape/automation; “APPROVED” / citizenship-granted stamps; UI that auto-prescribes legal action (“you must file OATS”); oversimplified three-PDF “done” flows.

**Sample data:** fictional Comune di Falsomonte / Ross–Rossi line; watermark `SAMPLE DATA - ATTO DEMO`; lived-in scan texture.

**Caveat:** Demo script beat uses “enterprise-grade local encryption” — compliance DR forbids absolute / empty security adjectives; align copy with threat-model facts only.

## Snippets

> Victory condition… “Case File Complete” / “Ready for Export,” never “Citizenship Granted.”

> Lead with High-Fidelity GIF/WebP Tiles interspersed with pristine Static Product Photography, explicitly avoiding a massive, autoplaying live-action video header.
