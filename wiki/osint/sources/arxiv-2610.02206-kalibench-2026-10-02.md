## Narrative

A benchmark that measures whether a model can turn a plain-language request into an **exact, executable** command-line invocation for a real security tool.

The scale: **8,504 query-command pairs**, spanning **1,642 tools**, 23 capability dimensions, and five security phases. Items were built from official documentation, generated by a model, then verified in three stages: an LLM verifier, execution in a sandboxed container, and human review. Scoring is runtime-free, using canonicalisation and alias-aware matching.

The results are the interesting part, because they show the failure sits in the arguments, not the tool choice.

| Setting | Result |
|---------|--------|
| Best open-weight model, unrestricted | 41.3% exact |
| Best proprietary, unrestricted | 61.68% exact |
| Tool selection, unrestricted to restricted | 72.0% to 95.2% |
| Optional-argument F1, unrestricted to hinted | 45.1% to 87.8% |
| Exact-correct, unrestricted to hinted | 22.3% to 73.1% |
| 8B model fine-tuned on the benchmark | 79.2 average total score |

Tool selection resolves once the candidate set is narrowed or the docs are supplied. Argument construction is the bottleneck. A small tuned model approaches a very large one on this task.

The authors admit the limits. Ground truth comes from manuals captured at build time, so upstream version changes can outdate items, and the manuals themselves contain inconsistencies. The verifier pipeline is imperfect. Single-turn only, and documentation-grounded.

**Defensive framing, per the authors:** the work introduces no new attack techniques and stays at single-command level. They position it for security education, vulnerability assessment, incident response, and forensics.

For this workspace: the reusable idea is the **runtime-free verifiable reward** built from canonicalisation plus alias-aware matching. That is a scoring design we could borrow for any tool-invocation gate of our own.

No PoC. No exploit steps. No command list on this page. The dataset licence is a docx-style claim and needs a `gh api` check before any use. No clone.
