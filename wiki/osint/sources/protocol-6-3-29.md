## Narrative

The emergence of large language model agents capable of invoking external tools has created urgent need for formal verification of agent protocols. Two paradigms dominate this space:Schema-Guided Dialogue(SGD), a research framework for zero-shot API generalization, and theModel Context Protocol(MCP), an industry standard for agent–tool integration.
