## Narrative

SparkToro launches **standalone public API** (separate product from web app subscription). Behavioral audience intelligence as **infrastructure** — agencies, in-house marketers, B2B SaaS signup enrichment. MCP server validated demand; API for production pipelines/agents at scale. **Credit-metered:** audience report = 10 credits; sections 1–5 credits; full pull ~23 credits. **200 free credits** on signup; packs from **$500 / 5,000 credits** (Agency bundle 50k for $3k). Same modeled affinity data as web app — directional, sanity-check before big budgets. Route to **seo-wiki** for GEO/AEO audience tooling — **not** TipDrop/David adopt.
