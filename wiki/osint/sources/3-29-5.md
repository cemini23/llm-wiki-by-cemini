## Narrative

COHORT is a ROS-based collaborative DNN inference and task-execution framework for multi-robot systems, using a hybrid offline–online RL strategy with Advantage-Weighted Regression to schedule and distribute DNN module execution across robots under real-time bandwidth/latency/battery constraints. The contribution is a multi-robot edge DNN-inference method. This is **out-of-scope** for Cemini's trading-stack research agenda — multi-robot inference orchestration has no application path to financial-market modeling or OSINT research.
