## Narrative

90 agent runs, same retrospective-board spec, 14-criterion rubric. **xHigh reasoning** lifted first-try perfect runs **28% → 89%** (~5× fewer corrective prompts) for **9–29%** more cost. Browser testing tool **+42–68% cost**, no functional gain. Frontier vs cheap model gap dominated. **CCC steal:** default to reasoning-tier bump before adding tool surface area; matches RSI/harness discipline vs tool sprawl.
