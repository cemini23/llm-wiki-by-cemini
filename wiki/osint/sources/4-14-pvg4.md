## Narrative

Memelang proposes a compact intermediate representation (IR) for LLMs to emit directly, deterministically parseable into hybrid vector-relational queries that compile to parameterized SQL. The core idea is an **axial grammar**: a linear token grammar where a small set of *ranked separator tokens* induce an n-dimensional coordinate system over an otherwise flat stream. A single left-to-right scan assigns each non-separator token a lattice coordinate; rank-r separators bump the rank-r axis and zero all lower ranks. The "embodiment" then interprets fixed coordinate positions as semantic roles (table / column / value), so an LLM emits structure without parentheses, indentation sensitivity, or clause-heavy keywords.

The design goals are deterministic single-pass parsing, streaming-friendly incremental validation (compatible with prefix-valid constrained decoding), a low-entropy surface form that reduces token count and clause permutations, bounded structural degrees of freedom, and a safe compilation boundary that preserves value parameterization (no string-concatenated SQL, reducing injection risk). Memelang adds coordinate-stable *relative references*, parse-time *variable binding* over a first-occurrence order, *carry-forward inheritance* (implicit context reuse along an axis to cut repetition), and inline tags on value terms encoding grouping, aggregation, and ordering — all derivable in one streaming pass. The paper supplies a reference lexer/parser, a coordinate-indexed IR, and a compiler emitting parameterized PostgreSQL SQL with optional pgvector similarity operators. Memelang is explicitly *not* a general programming language or a full SQL reimplementation; it deliberately omits arbitrary nesting and correlated subqueries.

**Cemini relevance**: Memelang is a generator-facing IR for the exact hybrid vector+relational query pattern the librarian's kb-server retrieval layer runs against pgvector. An axial-grammar IR could make LLM-emitted retrieval queries more reliable and injection-safe than free-form SQL or JSON tool-call schemas.
