## Narrative

LLM-powered GUI agents (for automated UI testing, AI assistants, vulnerability detection) capture the current screen as a structured representation — Android accessibility trees or web DOM trees — then reason and act over many rounds. The paper's motivating study shows this representation is the dominant cost driver: UI representation consumes **80–99% of total agent-token cost** across studied frameworks and benchmarks, creating a critical scalability bottleneck. The authors frame "UI representation optimization" (UI-PS) as automatically synthesizing programs that transform raw UI trees into compact, semantically complete forms. Two challenges make this hard: (1) **no Boolean oracle** — unlike traditional program synthesis with test-case assertions, UI-PS is a multi-objective problem balancing token reduction against semantic completeness with only soft/partial-credit signals; and (2) a **combinatorial program search space** — UI trees are deeply nested with hundreds of nodes, and transformation programs must compose correctly across the hierarchy, where a single fault cascades.

The proposed framework, **UIFORMER**, is the first automated optimizer for UI transformation programs. It (1) restricts the program space with a **domain-specific language (DSL)** capturing UI-specific operations, enforcing validity and shrinking search by construction; and (2) runs **LLM-based iterative refinement** under joint correctness and efficiency rewards. It operates as a lightweight plugin requiring minimal changes to existing agents. Across three UI-navigation benchmarks (Android + Web) and five LLMs, UIFORMER achieves **48.7–55.8% token reduction** with minimal runtime overhead while maintaining or improving task performance; a real-world deployment at WeChat validates practical impact.

**Cemini relevance**: directly informs UI-representation efficiency for any computer-use / GUI-automation agent — token-budget control is the same lever that governs cost and scalability for agentic browsing and tooling work in the conductor stack.
