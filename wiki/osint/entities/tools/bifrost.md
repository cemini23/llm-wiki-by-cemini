## Narrative

### What It Is

Bifrost is a high-performance MCP gateway and LLM proxy built in Go by Maxim AI. It serves a dual role: unified LLM proxy (routing to OpenRouter, Anthropic, Vertex AI) and federated MCP gateway with a novel **Code Mode**.

### Key Architecture

- **Language/Runtime**: Go-native. Deployed via Docker or `npx`.
- **Storage**: PostgreSQL + in-memory vector stores for configuration and cataloging.
- **Code Mode**: When enabled, replaces the entire tool catalog with 4 meta-tools:
  - `listToolFiles` — list available tool files
  - `readToolFile` — read specific tool documentation
  - `getToolDocs` — retrieve tool docs for a given capability
  - `executeToolCode` — execute a Starlark/Python script generated by the LLM
- **Execution Flow**: LLM → generates executable script → Bifrost sandbox executes → results returned. Consolidates multi-step workflows into a single turn.
- **Auth**: OAuth 2.0 with automatic token refreshing and explicit auto-approval rules.
- **Routing**: Built-in semantic caching, adaptive load balancing, provider fallbacks.

### Why Not for Cemini (Solo Dev)

Despite its power, Bifrost was **not recommended** for Cemini's current architecture because:

1. **Infrastructure overhead**: Requires PostgreSQL, Docker containers, and potentially Kubernetes — overkill for a solo developer on Mac Studio + single VPS.
2. **Code execution risk**: The LLM autonomously generates and executes Python/Starlark scripts. For financial systems handling Kalshi trades, a hallucinated script executing unintended trades is an unacceptable risk vector. This is deterministic-execution unsafe.
3. **Configuration complexity**: Requires Web UI navigation or complex JSON definitions for local stdio connections.
4. **Redundant routing**: If OpenRouter is already the LLM aggregator (as in Cemini's stack), Bifrost's built-in provider routing is redundant.

### When Bifrost Would Make Sense

- Multi-developer team with Kubernetes infrastructure
- Workflows requiring autonomous multi-step orchestration without human intervention
- Environments where sandboxed code execution is acceptable/desired
- Enterprise deployments with zero-trust network requirements
