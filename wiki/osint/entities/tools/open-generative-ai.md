## Raw Concept

From the Cemini Multi-Wiki Link Evaluation Report v3 (May 2026). MIT-licensed v1.0.11, 13.6k stars. Cross-platform desktop app with 200+ models, C++ inference engines (sd.cpp, Wan2GP), and dual-mode Image/Cinema Studio.

## Narrative

Open-Generative-AI provides foundational logic for advanced persona-ops: dual-mode Image Studio processing up to 14 reference images simultaneously, Cinema Studio with professional photographic parameter controls (Focal Length, Aperture), and the Generative-Media-Skills API enabling terminal-driven media generation.

**Tier: Steal-from** — extract C++ inference engine parameters (sd.cpp) for local rendering and the Generative-Media-Skills API logic. Do NOT adopt the full React/Electron desktop client (contradicts terminal-native, headless server deployment). MIT license safe for selective extraction. Cross-wiki routing: document the Generative-Media-Skills API architecture in CCC wiki for terminal-native image rendering.
