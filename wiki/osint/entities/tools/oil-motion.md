## Narrative

Interactive web animation framework for premium, responsive UI motion. Extracting selected animation patterns into the Atto web vault differentiates the digital presentation of civil-record agent kits from legacy genealogy platforms — supporting premium tier positioning ($499–899 kit, $15–40/mo playbook).

**Constraints:** strict performance budget on low-end mobile; verify no dependency conflicts with existing Atto Vault UI stack. No core human-gated truth backend changes.
