## Narrative

An expansive set of ready-to-use Agent Skills for high-level scientific research — molecular dynamics, time-series forecasting, geospatial analysis, and more. 135 skills across multiple scientific domains.

**Steal-from rationale**: The time-series forecasting skill templates are structurally valuable for market data ingestion within `/opt/cemini`. The plan is to extract the skill architectures and rewrite execution endpoints to query Cemini's proprietary PostgreSQL databases (replacing public bioinformatics arrays). The MIT license fully protects this adaptation path.

**Why not Adopt**: These skills are designed for scientific research data, not financial markets. Direct adoption would require significant rewrites of data sources and evaluation metrics. The steal-from pattern — extract structural patterns, rewrite execution — is the correct approach.

**OSINT cross-route**: Geospatial science skills documented for OSINT wiki's threat-actor geolocation workflows.
