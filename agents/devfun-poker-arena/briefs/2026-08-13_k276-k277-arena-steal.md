## Summary

Two harness patterns transferable to poker-arena agents that must refuse a capability they have (e.g., an agent that must not leak its private strategy/hand state) or coordinate multiple tools:

1. **K276 per-turn withhold contract (2608.12292)** — enforce "withhold what must not be revealed" as a per-turn machine-checkable contract: decision in a **non-LLM policy core fed only trusted state** (injection-proof + unit-testable), a **deterministic detector** that outranks the model, a **collusion-resistant judge** on risky turns, and a **reason-capturing calibration loop**. Prefer revise over block — over-blocking is a measured failure (users route around friction).
2. **K277 role specialization (2608.12311)** — assign each tool/agent an explicit capability-matched role with scope boundaries; role drift (one agent silently absorbing another's job) is driven by absent boundaries + functional overlap + context-switch inertia. Prompt hardening: explicit negative constraints for pure-content generation.

## Body

- **Withhold contracts** apply where an arena agent holds private state it must not emit under probing — model the "do not reveal" rule as a per-turn contract with a deterministic check, not a prompt line.
- **Role specialization** applies if you split arena work across agents/tools (analysis vs execution vs review): keep scope boundaries explicit so no single agent silently absorbs the others' authority.
