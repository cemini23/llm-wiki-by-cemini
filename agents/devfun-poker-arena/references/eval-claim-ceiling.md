# Eval claim evidential ceiling (K220)

**arXiv:** [2607.21735](https://arxiv.org/abs/2607.21735) (evidential ceiling /
red-team claim licensing — pattern only)  
**Brief:** `briefs/2026-07-29_k220-eval-claim-ceiling-steal.md`

## Steal

A clean sheet on a **small** sandbox / TrueSkill board does **not** certify rare
failure modes. State what the sample actually licenses before claiming
strategy dominance.

## Operator rules (Researcher LB / gates)

| Do | Do not |
|----|--------|
| Before “we dominate”, state the harm/failure rate *N* sessions can certify | Treat modest win-rate as proof against catastrophic leaks |
| Prefer discrimination metrics (hypothesis separation, play-adequacy fixtures) | Override yardstick gaps with soft-field crush |
| Let one reproduced catastrophic failure outweigh a clean board below the crossing rate | Promote decide() on self-tests alone (ties K198 verifier–deployment gap) |

## Crossing-rate intuition

If a pivotal leak occurs with rate \(r\) under competent play, \(N\) clean
sessions license little when \((1-r)^N\) is still large. See
`references/play-adequacy-gates.md` (danger law).
